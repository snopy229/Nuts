# PythonProject

This is a web application built with Python and Django, using the Wagtail CMS for content management.

## Key Technologies

*   **Backend:** Django, Django Ninja (for APIs)
*   **CMS:** Wagtail
*   **Asynchronous Tasks:** Celery with Redis
*   **Frontend:** The project is set up to use `django-vite`, suggesting a modern JavaScript-based frontend.
*   **Database:** PostgreSQL (inferred from `psycopg2-binary`)
*   **Other notable libraries:**
    *   `wagtailgeowidget` for geographical data.
    *   `django-phonenumber-field` for phone number handling.
    *   `wagtail-modeltranslation` for multilingual support.
    *   `django-ckeditor-5` and `django-trix` for rich text editing.

The project is currently under development.
